# 🧱🐱 Brick Cats — Interactive Framer Component

A playful interactive Framer code component that turns a studded brick baseplate into a living scene of animated cats.

Move your pointer across the component and the cats respond, look around, shift their brick-built forms, and interact with a soft hover glow. Every visual detail is customizable directly from Framer.

## ✨ Live Preview

**[View the live demo →](https://brickcats.framer.website/)**

## 🚀 What makes Brick Cats special

Brick Cats combines a procedural canvas animation with a toy-brick visual system made specifically for Framer. The cats are generated from animated brick cells rather than static illustrations, giving the component a distinctive responsive character.

- 🐱 Animated brick-built cats
- 🧱 Studded toy-brick baseplate
- 🖱️ Pointer-following interactions
- 👀 Cats react and look toward the pointer
- ✨ Optional interactive hover glow
- 💥 Brick drop / scale transitions
- 🎨 Fully customizable color system
- 📐 Adjustable stud size
- 🐈 Adjustable cat density
- ⚡ Adjustable animation speed
- 🧲 Adjustable hover strength
- ⏸️ Pause / play control
- 📱 Responsive to any Framer frame size
- 🖥️ Retina-aware rendering with DPR limiting
- ♿ Reduced-motion aware
- 💤 Pauses rendering when off-screen or when the page is hidden
- 🖼️ Framer static-renderer support

## 🎛️ Framer Controls

| Control | What it changes |
| --- | --- |
| **Baseplate** | Main studded background color |
| **Cat Body** | Primary cat body color |
| **Eyes** | Cat eye color |
| **Cool 1–3** | Cool edge colors used across the brick cats |
| **Warm 1–2** | Warm edge colors used across the brick cats |
| **Glow Color** | Pointer glow color |
| **Stud Size** | Size of each brick / stud cell |
| **Cat Density** | Number of cats distributed through the scene |
| **Speed** | Overall motion speed |
| **Hover Strength** | Strength of pointer interaction |
| **Hover Glow** | Show or hide the pointer glow |
| **Brick Drop** | Enable or disable brick drop transitions |
| **Paused** | Pause or play the animation |

## 🛠️ Add it to Framer

1. Open your Framer project.
2. Create a new **Code File**.
3. Name it `KarimSaifBrickCats.tsx`.
4. Copy the code from [KarimSaifBrickCats.tsx](./KarimSaifBrickCats.tsx).
5. Paste it into Framer.
6. Drag **Karim Saif Brick Cats** onto the canvas.
7. Resize it and customize everything from the properties panel.

## ⚡ Performance

The component is designed to stay practical inside Framer:

- Cached baseplate rendering
- DPR capped at 2
- ResizeObserver-powered responsive sizing
- IntersectionObserver-based visibility pausing
- Page visibility pausing
- Reduced-motion handling
- Static renderer detection
- requestAnimationFrame cleanup
- Bounded procedural layout calculations

For very large sections, increasing **Stud Size** can reduce the number of rendered cells and improve performance.
